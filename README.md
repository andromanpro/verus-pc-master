# VERUS Free

Открытый переносной инструмент ПК-мастера: диагностика, ручное обслуживание Windows, локальные клиенты, сметы и акты, резервные копии и обучение. Работает без подписки и активации флешки. Можно использовать в оплачиваемой работе.

**[Скачать сборку](https://github.com/andromanpro/verus-pc-master/releases)** · **[Free и планы Pro](docs/FREE-PRO.md)** · **[Сообщить об ошибке](https://github.com/andromanpro/verus-pc-master/issues)**

0.7.0 — первый публичный предварительный выпуск Free. Код проверен автоматическими тестами; совместимость аппаратных операций проверяйте на тестовом ПК перед выездом. `Verus.exe` не имеет подписи Authenticode. Подписанные пакеты обновлений используют отдельную подпись RSA.

## Первый запуск

1. Распакуйте сборку целиком в отдельную папку или на USB-накопитель.
2. Запустите `Verus.exe`. Для диагностики с полным набором датчиков и ремонтных операций может потребоваться разрешение администратора.
3. Заполните профиль мастера. Если сохраняете данные клиентов, задайте пароль базы в настройках и запишите резервный код отдельно от накопителя.
4. Начните с диагностики. Перед ремонтом подтвердите план работ и сделайте резервную копию данных клиента.

Поддерживаемая среда: Windows 10/11, Windows PowerShell 5.1, современный браузер. Ремонтные операции выполняйте только на компьютере, которым вам разрешено управлять.

Базовая сборка не включает чужие программы и драйверы. Температуры CPU требуют доступного датчика, обычно через отдельно установленный LibreHardwareMonitor. Отсутствующие показания отображаются как недоступные, а не как нулевая температура. Условия дополнительных утилит описаны в [реестре компонентов](THIRD_PARTY_NOTICES.md).

## Рабочий цикл

Приёмка → диагностика → резервная копия → согласованные работы → проверка результата → смета и акт передачи. История хранится локально. Доступны печать документов, сравнение показателей до и после, напоминания и сообщения, которые мастер отправляет сам.

Free включает локальные возможности без ограничения срока и числа клиентов. ИИ работает на вашем ключе провайдера; расходы на запросы оплачиваются провайдеру отдельно. Pro с управляемым ИИ, синхронизацией и командной работой пока планируется и не продаётся.

## Запуск из исходников

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File dashboard/server.ps1
```

Сервер открывает локальную страницу и слушает только loopback. Для резервного запуска используйте `dashboard/Dashboard.bat`. Никакой токен лицензии не нужен.

## Сборка и проверки

Требуются Python 3.14, Node.js для проверки JavaScript и Windows PowerShell 5.1. Браузерные проверки используют Playwright и Edge.

```powershell
py -3.14 -m pip install -r scripts/requirements-test.txt
py -3.14 scripts/check-public-scope.py
py -3.14 scripts/test-ui.py
node scripts/test-intake-storage.js
node scripts/test-riskcard.js
powershell -NoProfile -File scripts/test-temperature-sources.ps1
powershell -NoProfile -File scripts/test-agent-invariants.ps1
powershell -NoProfile -File scripts/test-update-package.ps1
py -3.14 scripts/test-ui-browser.py --channel msedge
py -3.14 scripts/test-free-api.py
py -3.14 scripts/build-public.py --output dist/public-source
```

Сборка переносной версии из чистого публичного каталога:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File flash-staging/build-flash.ps1 -SkipPortable
```

Браузерные проверки используют вымышленные данные. Проверки API создают отдельную временную базу; они не запускают очистку, изменение сети или ремонт ОС. Аппаратные операции дополнительно проверяются вручную на тестовой системе.

## Структура

- `dashboard/` — интерфейс и локальный сервер.
- `training/`, `markdown/`, `field-handbook/` — учебные материалы и справочник.
- `scripts/` — сборка и проверки.
- `flash-staging/` — сборка переносного комплекта и исходник запускающей программы.

Личные настройки, клиенты, ключи и загруженные программы не входят в репозиторий. О безопасности: [SECURITY.md](SECURITY.md). Для участия: [CONTRIBUTING.md](CONTRIBUTING.md).
