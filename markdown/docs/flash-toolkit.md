# Инструментарий домашнего ПК-мастера (флешка)

> Состав загрузочной флешки и портативного софта для честного ремонта.
> Все ссылки — только официальные сайты (проверено 2026-05). ---

## Главный принцип: только официальные источники

Это не занудство. Это основа честного сервиса — и твоя личная безопасность:

- **Никаких «сборок», «RePack», торрентов, «активаторов».** В них часто зашиты майнеры и стилеры паролей. Принесёшь такое клиенту — угробишь репутацию с первого дня (а репутация — это весь твой заработок).
- **Скачивай с офсайта.** При установке **снимай галки** «доп. софт» (Яндекс, Avast, MyAshampoo и т.п.) — это и есть то, чем разводилы засоряют чужие компы.
- **Предпочитай open-source и портативные версии**: их код видно насквозь, устанавливать не надо, и мусора после себя они не оставляют.

### Лицензии — важно для честного сервиса
Часть антивирусных сканеров (Kaspersky, Dr.Web) бесплатны **только для личного использования**. Для платного сервиса это серая зона. Честный путь:
- основная проверка — **встроенный Microsoft Defender + Microsoft Safety Scanner** (бесплатно, в т.ч. де-факто на машине клиента) и **ESET Online Scanner**;
- портативные сканеры (KVRT, CureIt) — для разовой помощи знакомым/себе; для бизнеса со временем оформить разрешённые лицензии;
- никаких «крякнутых» антивирусов — это противоречит всей идее.

## 0. Сама флешка

- Объём **от 32 ГБ** (лучше 64–128), USB 3.0+. На неё ставится мульти-загрузчик, в который ты просто копируешь ISO-образы.
- Вторую флешку/диск держи под **бэкап данных клиента** (нельзя лить чужие файлы на рабочую флешку с тулзами).

**Ventoy** — мульти-загрузчик: ставишь один раз, потом просто кидаешь любые `.iso` на флешку, и они все появляются в загрузочном меню.
→ https://www.ventoy.net/en/download.html
(альтернатива для одного образа — Rufus: https://rufus.ie/)

## 9. Бэкап и восстановление данных

**Перед любой переустановкой — сначала бэкап данных клиента. Всегда.**

| Тула | Зачем | Офсайт |
|---|---|---|
| **Veeam Agent for Windows (FREE)** | Полный образ системы / бэкап | https://www.veeam.com/ |
| **Clonezilla** | Клонирование диска (например, при переезде на SSD) | https://clonezilla.org/ |
| **TestDisk / PhotoRec** | Восстановление удалённых/потерянных файлов, open-source | https://www.cgsecurity.org/ |
| **DMDE (Free)** | Мощное восстановление файлов/разделов; free-версия — до 4000 файлов за операцию | https://dmde.com/ |
| **Windows File Recovery (winfr)** | Официальная утилита Microsoft, бесплатно (из Microsoft Store) | https://apps.microsoft.com/detail/9n26s50ln705 |
| **R.saver** | Простой мастер, рус.; ⚠ бесплатна **только для НЕкоммерческого** использования | https://rlab.ru/tools/rsaver.html |
| **Recuva** | Простой GUI для удалённых файлов; ⚠ как CCleaner — снимай галки/телеметрию при установке | https://www.ccleaner.com/recuva |

> ⚠️ **Главные правила восстановления (важнее любого софта):**
> 1. **Не пиши на тот же диск.** Восстановленные файлы сохраняй на ДРУГОЙ носитель — иначе затрёшь то, что спасаешь.
> 2. **Диск физически сыпется** (стучит, щёлкает, пропадает из системы)? Выключи и не гоняй. Сначала снять побайтовый образ (**GNU ddrescue** из Linux Live / Hiren's) и работать с копией — либо в лабораторию. Лишние включения убивают шансы.
> 3. Восстановление данных часто оказывается самой ценной услугой — данные для клиента бесценны, и цену стоит ставить по результату, а не по времени работы.

## Чек-лист сборки флешки

- [ ] Поставил Ventoy на флешку 64+ ГБ
- [ ] Скопировал ISO: Hiren's BootCD PE, Windows 10/11, Linux Live, MemTest86+
- [ ] Папка `Portable/` с распакованным портативным софтом (разделы 2–9)
- [ ] Папка `Drivers/` со свежим SDIO-снимком
- [ ] VERUS с настроенным профилем и проверенным резервированием
- [ ] Вторая флешка/диск отдельно — **только под данные клиентов**
- [ ] Текстовый файл «откуда что качал» (офсайты) — чтобы обновлять, не вспоминая

## Что обновлять регулярно
Антивирусные базы — каждый выезд (KVRT/CureIt качай заново, они с базами внутри). Остальное — раз в 1–2 месяца.
