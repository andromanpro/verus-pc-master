# Словарь терминов мастера

Все слова, которые встречаются в дашборде, справочнике, на форумах и в разговоре с клиентом. Объяснения — **простыми словами**, понятными даже неподготовленному человеку.

К каждому термину — где это в дашборде, в каком кейсе справочника или в каком месте работы встречается.

## Железо

**CPU** (Central Processing Unit, центральный процессор) — «мозг» компьютера. Считает, выполняет программы. Бывает Intel, AMD, ARM (в новых Mac и некоторых ноутах). Параметры: количество ядер (4/6/8/16), частота (ГГц), TDP (сколько тепла выделяет).

**GPU** (Graphics Processing Unit, видеокарта) — рисует картинку на экран. Бывает встроенная (внутри процессора, для офиса) и дискретная (отдельная плата, для игр / видео / нейросетей). NVIDIA / AMD / Intel.

**VRAM** — память видеокарты (в гигабайтах). Игре нужно много VRAM для текстур; офисной работе — почти не нужно.

**RAM** или **ОЗУ** — оперативная память. Где Windows и программы хранят данные пока работают. Чем больше — тем больше программ можно открыть. 8 ГБ — минимум для Windows 10/11 сегодня, 16 ГБ — комфортно, 32+ ГБ — для игр или работы.

**Материнская плата** (или просто «мать», «мама», «motherboard», «mobo») — большая плата, к которой подключено всё остальное. Не работает сама по себе — она «дорога» между компонентами.

**БП** (блок питания, PSU = Power Supply Unit) — преобразует ток из розетки в тот, который нужен ПК. Параметры: мощность (Вт), сертификат КПД (80+ Bronze / Silver / Gold). Дохнущий БП — частая причина случайных перезагрузок и BSOD.

**Чипсет** — управляющая микросхема на материнке. Определяет какие процессоры поддерживаются, сколько USB и т.д. Из жизни мастера: важно знать какой чипсет, чтобы понимать совместимость при апгрейде CPU.

**Сокет** — разъём процессора на материнке. AM4, AM5 (AMD); LGA 1700, LGA 1851 (Intel). Процессор подходит только в свой сокет, в чужой не воткнёшь.

**Термопаста** — серая паста между процессором и радиатором. Высыхает за 2-3 года → ПК начинает перегреваться. Стандартная задача мастера на чистке: поменять.

**Радиатор + кулер** — металлическая «решётка» с трубками + вентилятор. Греется от процессора, дует на радиатор. Грязный (забит пылью) = ПК тормозит и шумит.

**TDP** (Thermal Design Power) — сколько ватт тепла выделяет процессор/GPU под нагрузкой. Чем больше — тем толще нужен радиатор.

## Накопители (диски)

**HDD** (Hard Disk Drive) — обычный механический жёсткий диск. Крутит «блины». Дешёвый, но медленный. На 2026 — устаревшая технология для системного диска, оставлять только под архивы.

**SSD** (Solid State Drive) — твердотельный накопитель. Без движущихся частей, в 10-50 раз быстрее HDD. Минусы: дороже, и есть «износ» (ограниченное число перезаписей, на практике 5-10 лет работы для бытового SSD).

**NVMe** — самый быстрый тип SSD, подключается напрямую к шине PCIe. На вид — длинная «жвачка» (M.2 форм-фактор). До 7000 МБ/с скорость. Стандарт для современных ПК.

**SATA** — старый интерфейс подключения. Для HDD и медленных SSD (2.5'' формат). Скорость до 600 МБ/с.

**M.2** — слот на материнке для NVMe-дисков. Маленькая «жвачка» прямо на материнке, без проводов.

**SMART** (Self-Monitoring, Analysis and Reporting Technology) — самодиагностика, встроенная в диск. Показывает: сколько часов работал, сколько ошибок, температуру, остаток ресурса. Читается программой **CrystalDiskInfo**.

Параметры SMART которые важны:
- **Power-On Hours** — сколько часов диск проработал всего. 30 000+ для HDD — старый, пора менять.
- **Reallocated Sectors Count** — сколько повреждённых секторов диск переназначил. Любое значение > 0 — диск начал умирать.
- **Wear Leveling Count** (для SSD) — износ. 100 = новый, 0 = израсходовал ресурс полностью. Меньше 20 = пора менять.
- **Total LBA Written** (для SSD) — сколько данных записано за жизнь. Помогает оценить «бытовой» или «майнерский» SSD.

**Бэд-сектор** (bad sector) — повреждённое место на диске. На HDD — физическое повреждение, на SSD — выработанная ячейка. Симптомы: «висит при попытке прочитать файл», «диск пропадает на минуту».

**Клонирование** — копирование одного диска на другой так, чтобы новый стал точной копией старого и грузил Windows. Программы: Macrium Reflect Free, AOMEI Backupper, Acronis (платный).

## Память (ОЗУ)

**DDR3 / DDR4 / DDR5** — поколения оперативной памяти. **НЕ совместимы между собой**: DDR3 не воткнёшь в слот DDR4, физически разные ключи. На 2026 актуальны DDR4 (большинство) и DDR5 (новые).

**Частота памяти** — например 2400 МГц, 3200 МГц, 5600 МГц. Чем выше — тем быстрее. **Не вся частота поддерживается** — ограничение от мат.платы и процессора.

**Dual channel** — режим работы памяти когда стоят две одинаковые планки в правильных слотах (обычно через один: A2 + B2). Даёт +15-30% скорости. Если воткнуть в неправильные слоты — будет single channel, медленнее.

**MemTest86+** — программа тестирования памяти. Грузится с флешки до Windows, гоняет на ОЗУ паттерны несколько часов. Если ошибки — память дохлая (или мат.плата). Стандарт мастера.

**SODIMM** — формат памяти для ноутбуков (короткие планки). DIMM — для настольных (длинные).

## Загрузка ПК и BIOS

**BIOS** (Basic Input/Output System) — мини-программа в чипе на материнке, которая запускается раньше Windows. Раньше у всех был BIOS, сейчас почти везде **UEFI** (более новая версия).

**UEFI** (Unified Extensible Firmware Interface) — современная замена BIOS. Графический интерфейс, поддержка дисков > 2 ТБ, безопасная загрузка. Все ПК после 2012 года.

**POST** (Power-On Self Test) — самопроверка ПК при включении. ПК «пикает» (если есть динамик) и проверяет: процессор есть, память есть, видео есть. Если что-то не так — пишет ошибку или пикает в особом ритме.

**Secure Boot** — функция UEFI: разрешает загрузку только подписанных загрузчиков (Windows, лицензированный Linux). Защищает от руткитов в загрузке. Иногда мешает (например, загрузке Hiren's с флешки) — тогда временно отключают в UEFI.

**Bootloader** (загрузчик) — программа на диске, которая запускается после BIOS/UEFI и загружает Windows. Файлы: `\EFI\Microsoft\Boot\bootmgfw.efi` (UEFI) или `bootmgr` (BIOS-style).

**MBR vs GPT** — два способа разметки диска. MBR старый, до 2 ТБ. GPT новый, без ограничения. Для UEFI нужен GPT.

**Раздел** (partition) — диск разделён на куски, каждый кусок видится в Windows как отдельная буква (C:, D:). Системный раздел — где лежит Windows. EFI-раздел — где загрузчик (маленький, ~100 МБ).

## Windows внутри

**Реестр** (Registry) — большая база настроек Windows. Хранится в файлах `C:\Windows\System32\config\`. Редактируется через `regedit`. **Не лезь туда без чёткого понимания зачем** — можно сломать ОС.

**Службы** (Services) — фоновые программы Windows. Видны в `services.msc`. Примеры: Защитник Windows, Windows Update, Печать. Можно остановить / запустить / выключить.

**Драйвер** — программа-«переводчик» между Windows и железом. Один драйвер для видеокарты, другой для сетевой, третий для принтера. Старый или битый драйвер — частая причина BSOD.

**SFC** (System File Checker) — встроенная в Windows утилита. Команда: `sfc /scannow`. Проверяет целостность системных файлов, чинит повреждённые.

**DISM** (Deployment Image Servicing and Management) — более глубокая утилита. Команда: `DISM /Online /Cleanup-Image /RestoreHealth`. Чинит хранилище компонентов (`C:\Windows\WinSxS`).

**WinSxS** — папка на 5-15 ГБ, где Windows хранит резервные копии своих компонентов. Можно почистить (кнопка «🧼 Чистка WinSxS» в дашборде), освободить место.

**UAC** (User Account Control) — окошко «Разрешить этой программе вносить изменения?». Защита Windows от незаметных установок. Бывает раздражает, но **не выключай** — это серьёзная защита.

**Безопасный режим** — Windows грузится только с минимумом драйверов. Используется когда что-то мешает обычной загрузке (вирус, кривой драйвер). Заход: Shift + Перезагрузка → Доп.параметры → Перезагрузка → клавиша 4 (или F4).

**Точка восстановления** — снимок состояния Windows, можно откатиться если что-то сломал. Создаётся вручную или автоматически перед обновлениями. Восстанавливает: реестр, системные файлы. НЕ восстанавливает: твои файлы (Документы, Изображения).

**Журнал событий** (Event Log, eventvwr.msc) — Windows записывает туда все ошибки, предупреждения, информацию. Раздел «Система» — что с ОС. Раздел «Приложения» — что с программами.

**Диспетчер задач** (Task Manager) — `Ctrl+Shift+Esc`. Показывает процессы, нагрузку CPU/RAM/Disk, автозагрузку.

**Защитник Windows** (Windows Defender) — встроенный антивирус. На 2026 — приличный, ловит большинство угроз. Старые ПК с Windows 7/8 — он слабее.

**Активация Windows** — Windows проверяет что у тебя есть лицензия. Без активации — водяной знак «Активируйте Windows» в углу и некоторые ограничения настройки. Легальная активация — только через настоящий ключ (купленный у Microsoft или ОЕМ-партнёра). Активаторы (KMS) — нелегально и опасно (вирусы под видом активаторов).

## Сеть и интернет

**IP-адрес** — адрес устройства в сети. Похоже на номер дома. Локальный: `192.168.x.x` (в твоей домашней сети). Внешний — какой видит интернет (один на всю квартиру обычно).

**DNS** (Domain Name System) — переводит имена сайтов в IP. Если набрал `youtube.com`, твой ПК спрашивает у DNS «какой у него IP?» и получает ответ типа `142.250.184.78`. Если DNS не работает — сайты «не открываются по имени, но работают по IP».

**Шлюз** (Gateway) — адрес роутера в твоей сети. Обычно `192.168.0.1` или `192.168.1.1`. Через него весь твой трафик идёт в интернет.

**Маска подсети** — определяет какие IP в твоей сети, какие в чужой. Обычная: `255.255.255.0`. Не лезь без понимания.

**MAC-адрес** — уникальный «отпечаток» сетевой карты, например `00:1B:44:11:3A:B7`. Не меняется (почти). Используется в локальной сети.

**ping** — команда «пинг», проверяет доступен ли сервер. `ping 8.8.8.8` — если отвечает, интернет есть. `ping ya.ru` — если отвечает, DNS работает.

**tracert** — показывает путь пакета до сервера: через какие узлы он идёт. Помогает найти где обрыв.

**TCP / UDP** — два главных протокола передачи. TCP надёжный, медленный, для веба и файлов. UDP быстрый, без гарантий, для видео-/голосовых звонков.

**HTTPS** — защищённый HTTP. Между сайтом и тобой шифруется. Зелёный замок в браузере. Использует **TLS**.

**TLS** (Transport Layer Security) — протокол шифрования. Раньше назывался SSL. **Это его «расфрагментируют» GoodbyeDPI и zapret** чтобы обойти TSPU.

**MTU** (Maximum Transmission Unit) — максимальный размер пакета. Обычно 1500 байт. Если меньше — пакеты режутся, скорость падает. Иногда нужно менять для PPPoE-провайдеров.

**NAT** (Network Address Translation) — твой роутер «прячет» все ПК квартиры за одним внешним IP. Поэтому из интернета не видно сколько у тебя устройств.

**Wi-Fi 2.4 ГГц vs 5 ГГц** — две частоты. 2.4 — медленнее, но дальше пробивает стены. 5 — быстрее, но ближе. В роутере включай **оба сразу**, телефон/ноут сам выберет.

## Безопасность

**Антивирус** — программа защиты. Бесплатные приличные: Microsoft Defender (встроен), Malwarebytes Free (одноразовое сканирование), Касперский Free (платный лучше).

**Brandmauer / Firewall** — фильтр сетевого трафика. Решает «этой программе разрешить выход в интернет?». Встроен в Windows.

**BitLocker** — шифрование диска от Microsoft. Если включено и нет ключа — данные восстановить **невозможно** (это и есть смысл шифрования). Проверь у клиента ДО любой работы с диском.

**TPM** (Trusted Platform Module) — чип на материнке для безопасности (хранит ключи BitLocker, нужен для Windows 11). У новых ПК есть, у старых может не быть.

**Руткит** — самый зловредный тип вируса. Прячется глубоко в системе, видит и контролирует всё. Лечится только переустановкой ОС с форматированием.

**Троян** — программа, которая выдаёт себя за нужную (типа «активатор», «скачать кино бесплатно»), а внутри ворует пароли/майнит/шифрует.

**Adware** — навязчивая реклама. Меняет стартовую страницу браузера, открывает попапы. Не «вирус» в строгом смысле, но клиента бесит.

**Ransomware** — вымогатель. Шифрует файлы клиента и просит выкуп. **Не плати**, расшифровка не гарантирована. Лечение: восстановить из бэкапа.

**Майнер** — вирус, который тайно использует ПК клиента для добычи криптовалюты. Симптомы: ПК всегда жарится, тормозит даже без открытых программ.

**Фишинг** — поддельные сайты/письма выманивающие пароли. К ПК мастера не относится напрямую, но клиента предупредить — твоя задача.

**Двухфакторка (2FA)** — вторая защита аккаунта (SMS, приложение Authenticator). Рекомендуй клиенту настроить на важных аккаунтах (банк, почта).

## Замедления и DPI

**DPI** (Deep Packet Inspection) — глубокий анализ пакетов. Провайдер смотрит **что** в каждом сетевом пакете, а не просто **откуда** и **куда**. Так Роскомнадзор узнаёт что ты заходишь на YouTube и замедляет.

**TSPU** (технические средства противодействия угрозам) — российское оборудование DPI, установленное у провайдеров с 2022. На 2026 — основная причина замедления YouTube/Telegram в РФ.

**GoodbyeDPI** — open-source утилита от ValdikSS. Меняет фрагментацию TLS-пакетов чтобы TSPU не мог их «прочитать» и замедлить. Локально, без VPN. Ставится как Windows-сервис.

**zapret** — продвинутый аналог GoodbyeDPI. Больше стратегий, есть UDP-режимы (помогают со звонками в Telegram).

**WinDivert** — низкоуровневая системная штука, которую использует GoodbyeDPI и zapret. Перехватывает сетевые пакеты до отправки и меняет их. Драйвер ставится автоматически.

**VPN** (Virtual Private Network) — виртуальная частная сеть. Весь твой трафик идёт через зарубежный сервер. **Это не DPI bypass — это другой принцип.**

**Outline / AmneziaVPN** — конкретные VPN-инструменты. Open-source, ставится клиенту на свой VPS. Не «коммерческий сервис», а DIY-решение.

**Замедление vs Блокировка** — провайдер может замедлять (страница грузится, но 10 секунд вместо одной) или блокировать (страница не открывается совсем). GoodbyeDPI лечит замедление; блокировку — только VPN.

## Диагностика

**Тротлинг** (throttling) — процессор/видеокарта снижают частоту чтобы не сгореть от перегрева. Симптом: тормоза под нагрузкой даже на новом ПК. Лечится чисткой пыли + новая термопаста.

**BSOD** (Blue Screen of Death, «синий экран смерти») — критическая ошибка Windows. ПК показывает синий экран и перезагружается. **Код ошибки** на экране — главное что надо запомнить (например `MEMORY_MANAGEMENT`, `IRQL_NOT_LESS_OR_EQUAL`). Гугль по коду подсказывает причину.

**Bugcheck** — то же что BSOD, но техническое название.

**Kernel Panic** — аналог BSOD в Linux/macOS.

**Перегрев** — температура процессора/GPU выше нормы. CPU норма до 70°C, тревога после 85°C. GPU норма до 75°C, тревога после 85°C. Часовая нагрузка с температурой выше 90°C — деградация чипа.

**WMI** (Windows Management Instrumentation) — внутренний API Windows для получения данных о системе. Дашборд читает SMART, температуру и др. через WMI.

**ACPI** (Advanced Configuration and Power Interface) — стандарт управления питанием. Через ACPI Windows управляет вентиляторами и читает термодатчики.

**Stress test** — нагрузочное тестирование. CPU/GPU/Память грузится по максимуму на 5-60 минут, смотрят: стабильно работает? Не перегревается? Не вылетает? Программы: Prime95, OCCT, AIDA64. В дашборде есть встроенный 60-секундный.

**Bottleneck** — «узкое место». Процессор слишком медленный для видеокарты → видеокарта недогружается → FPS низкий. Чинится апгрейдом узкого места.

## Файлы и форматы

**ISO** — образ диска. Один файл, в котором «упакован» целый CD/DVD/флешка. Используется чтобы записать на флешку и загрузиться (например, Windows installer ISO).

**Rufus** — программа записи ISO на флешку. Стандарт.

**.zip / .7z / .rar** — архивы. 7z самый эффективный.

**.exe** — исполняемый файл Windows. Программа.

**.msi** — установщик Windows.

**.bat** / **.cmd** — командные файлы. Запускаются как программы, но внутри текст команд cmd.

**.ps1** — скрипт PowerShell. Современная замена .bat.

**.log** — текстовый файл с записями (журнал работы программы).

**.dmp** — minidump. Файл с состоянием памяти в момент BSOD. Используется для отладки причины синего экрана. Лежит в `C:\Windows\Minidump\`.

**Профиль пользователя** — папка `C:\Users\<имя>\`. Внутри: Documents, Desktop, Downloads, Pictures, AppData (там настройки программ). Бэкапить — это копировать профиль.

**AppData** — папка скрытая, внутри `C:\Users\<имя>\AppData\`. Roaming — настройки которые путешествуют с учёткой. Local — настройки только для этого ПК. **Часто там лежат важные базы данных программ** (Outlook PST, Thunderbird профиль, Steam игры в неправильной настройке).

## Безопасность мастера

**ESD** (Electrostatic Discharge, электростатический разряд) — статический заряд который собирается на теле человека (особенно в синтетической одежде, зимой). Разряд 200-300 В убивает CPU/RAM/SSD-контроллер, при этом человек его **не чувствует** (порог восприятия ~3000 В). Лечится антистатическим браслетом или прикосновением к заземлённому корпусу ПК перед работой.

**Антистатический браслет (ESD-браслет)** — ремешок на запястье с проводом до батареи/корпуса ПК. Снимает заряд с тела на «землю». Стоит 100-300 ₽, обязателен при работе с компонентами.

**Li-Po** (Lithium Polymer, литий-полимерный аккумулятор) — батарея во всех ноутбуках/ультрабуках/смартфонах с 2010 г. Опасна при проколе/сжатии — горит температурой 800°C. Признак неисправности — вздутие («крышка ноута не закрывается»). Транспортировать в специальном термостойком пакете (LiPo Bag).

**Write-blocker** — флешка или адаптер с физическим переключателем «защита от записи». Шифровальщик с заражённого ПК не сможет писать на такую флешку. Профессиональный инструмент мастера, цена 700-1500 ₽.

**Autorun** — механизм автозапуска `autorun.inf` с подключаемой флешки. Раньше использовался для меню запуска, сейчас — главный вектор заражения. Отключается через `gpedit.msc` → Политики автозапуска.

**CSAM** (Child Sexual Abuse Material) — материалы насилия над несовершеннолетними. Уголовное дело по ст. 242.1 УК. Если нашёл при работе у клиента — **не копируй** (хранение), **не удаляй** (уничтожение улик), сообщи по 102/112 как очевидец.

**Шифровальщик** (ransomware) — вирус который зашифровывает файлы и требует выкуп. Современные виды: LockBit, BlackCat, Conti. Лечится только из бэкапа — заплатил выкуп = только в 30% случаев получил ключ. Профилактика — бэкап 3-2-1 + отключение autorun.

**Удалённый доступ** (Remote Access) — AnyDesk / RustDesk / TeamViewer / Anymee. Программы которые позволяют видеть/управлять чужим ПК через интернет. Главная угроза — мошенники звонят клиенту якобы «от мастера», просят установить AnyDesk и снимают деньги с банка.

## Юридика и документы

**Самозанятый (НПД)** — налог на профессиональный доход. Режим для физлиц-фрилансеров. 4% с физлиц, 6% с юрлиц. Без отчётности, через приложение «Мой налог». Лимит — 2,4 млн ₽/год.

**ИП** — Индивидуальный Предприниматель. Следующий уровень после самозанятости (когда оборот > 2,4 млн/год или нужны наёмные работники). Сложнее в плане отчётности, но шире права.

**Акт приёмки** — документ ДО работы. Зафиксирована марка/модель/серийник ПК, внешние повреждения, жалоба клиента, согласие на бэкап. Подписи обоих. Главная страховка мастера.

**Акт передачи** — документ ПОСЛЕ работы. Что сделано, что не открывалось (документы клиента), что осталось «под риском» (диск с износом 88% и т.п.), гарантия 14 дней, подписи.

**Оферта** — публичное предложение на сайте/Авито. Юридически равно договору если клиент «совершил действия по принятию» (заказал услугу). Содержит: предмет, цена, сроки, гарантия, ответственность.

**Претензия** — письменное обращение клиента «не доволен, требую возврат/компенсацию». По ЗОЗПП у мастера **10 дней** на ответ. Молчание = признание. Ответ — заказным письмом, фактами, без «извините» (это признание вины в суде).

**ЗОЗПП** — Закон «О защите прав потребителей» 1992 г. Базовый документ при споре «мастер vs клиент-физлицо».

**Неустойка по ст. 28 ЗОЗПП** — 3% от цены работы за каждый день просрочки если мастер не уложился в обещанный срок. Защита: не называй конкретные сроки если не уверен.

**Удержание имущества — ст. 359 ГК** — право мастера не возвращать ПК клиента до оплаты услуг. Должно быть прописано в акте приёмки.

**Судебный приказ** — упрощённое судопроизводство (ст. 121 ГПК) для взыскания до 500 000 ₽. Госпошлина 400-800 ₽, без присутствия сторон, 5 дней рассмотрение. Дешевле обычного иска в 10 раз.

**152-ФЗ** — Федеральный закон «О персональных данных». Мастер — обработчик ПДн клиента. Нельзя открывать/копировать без согласия. Штраф до 500 тыс. за нарушение, до 2 млн при утечке.

## Спецтехника

**BGA** (Ball Grid Array, шариковая решётка) — тип крепления чипа к материнской плате (без ножек, на шариках припоя). Замена BGA-чипа требует специального оборудования (термостол, инфракрасная паяльная станция) и опыта. Без подготовки — не браться.

**Шарниры** (loop hinges) — петли крышки ноутбука. Типичная поломка у HP Pavilion, дешёвых Acer/Lenovo: пластик у крепления петель трескается, крышка ходит туго или болтается. Замена корпуса 3-5 тыс ₽ + работа.

**Матрица** (LCD-панель) — экран ноутбука. Заказывается по **part-number** с шильдика самой матрицы (например, `Innolux N140HCA-EAC`), не по модели ноута. В одной модели может быть 3-4 варианта матриц.

**Part-number** — артикул конкретного экземпляра комплектующего. Уникальный код для заказа точно такой же детали. Смотреть на наклейке на самой детали (на матрице ноута, на видеокарте, на материнке).

**NAS** (Network Attached Storage) — сетевое хранилище. Маленький компьютер с дисками и веб-интерфейсом, доступный по локальной сети. Популярные: Synology (DiskStation), QNAP, TerraMaster. Для дома обычно 2-диска в RAID-1.

**RAID** (Redundant Array of Independent Disks) — массив дисков для надёжности/скорости. Виды:
- RAID-0 — 2 диска, скорость х2, но при отказе одного — потеря данных
- RAID-1 — зеркало, надёжность, объём = объём одного
- RAID-5 — от 3 дисков, выдерживает отказ 1, объём = N-1
- RAID-10 — комбинация 0 и 1

**Mesh-сеть** (mesh-Wi-Fi) — несколько Wi-Fi-точек которые работают как одна большая сеть с бесшовным переходом. Бренды: Keenetic (российский), TP-Link Deco, Asus AiMesh. Для квартиры 70+ м² или дома с толстыми стенами.

**IoT** (Internet of Things, интернет вещей) — умные устройства подключенные к Wi-Fi: лампочки, термостаты, камеры, колонки с Алисой. Часто работают **только на 2.4 ГГц Wi-Fi**, не на 5 ГГц.

**ICC-профиль** — цветовой профиль монитора. Создаётся колориметром (X-Rite, Datacolor SpyderX). Нужен фотографам/дизайнерам/печатникам — без него цвета на экране не совпадают с печатью.

**Колориметр** — прибор для калибровки экрана. Прикладывается к матрице, измеряет цвета, создаёт ICC-профиль. Цена 15-25 тыс ₽, услуга мастера с прибором — 2000-3000 ₽ за монитор.

**Bottleneck** («узкое место») — самый медленный компонент в системе, который тормозит весь ПК. Современная видеокарта в старый процессор — узкое место CPU, GPU простаивает. Балансировка цены процессор:видеокарта 1:1.5-2 для игрового ПК.

**Термопаста** — паста между процессором и кулером для теплоотвода. Заменяется раз в 2 года (для ноута) или 3-5 лет (десктоп). Хорошие марки: Arctic MX-4, Noctua NT-H1, Thermal Grizzly Kryonaut. Дешёвая КПТ-8 — устарела.

## Командная строка

**CMD** (Command Prompt) — старая командная оболочка Windows с 1993 г. Базовые команды: `dir`, `cd`, `copy`, `ping`. Простой и совместимый.

**PowerShell** — современная командная оболочка с 2009 г. Команды вида `Verb-Noun`: `Get-Process`, `Stop-Service`, `New-Item`. Мощнее, объектно-ориентированная.

**WinRE** (Windows Recovery Environment) — среда восстановления Windows. Запускается из BIOS или после 3-х неудачных загрузок подряд. Из неё можно: командная строка, восстановление из точки, безопасный режим, сброс ПК.

**MBR** (Master Boot Record) — первый сектор диска со старой схемой загрузки. Для дисков < 2 ТБ. Лечится через `bootrec /fixmbr`.

**GPT** (GUID Partition Table) — современная схема загрузки. Для дисков > 2 ТБ, для UEFI-систем. Лечится через `bcdboot`.

**UEFI** (Unified Extensible Firmware Interface) — современная замена BIOS (с ~2012 г.). Графический интерфейс, поддержка дисков > 2 ТБ, Secure Boot.

**Secure Boot** — функция UEFI которая запрещает загрузку неподписанных ОС. Иногда мешает запуску Linux/спасательных дисков — приходится отключать в BIOS.

**SFC** (System File Checker) — встроенная утилита проверки целостности системных файлов Windows. Команда `sfc /scannow`.

**DISM** (Deployment Image Servicing and Management) — утилита для работы с образами Windows. Команда `DISM /Online /Cleanup-Image /RestoreHealth` чинит хранилище компонентов (откуда sfc берёт эталоны).

**CHKDSK** (Check Disk) — проверка файловой системы NTFS и физических секторов диска. `chkdsk C: /f /r` — починка + bad-сектора.

**Реестр** (Registry) — база настроек Windows. Открывается через `regedit`. Главные ветки:
- `HKLM` — настройки для всех пользователей
- `HKCU` — настройки текущего пользователя
- `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run` — автозагрузка системная

**Robocopy** (Robust File Copy) — продвинутая утилита копирования файлов с поддержкой повторных попыток, многопоточности, зеркалирования. Стандарт для бэкапов на Windows.
