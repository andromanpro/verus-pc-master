# Безопасность

Об уязвимостях сообщайте автору лично: [@andromanpro](https://t.me/andromanpro). Не публикуйте рабочие ключи, данные клиентов или детали эксплуатации в открытом issue. Укажите версию, минимальный пример на вымышленных данных и ожидаемое поведение. Срок ответа не гарантируется.

Исправления безопасности выпускаются для актуальной версии Free и доступны без подписки.

## Границы защиты

- HTTP-сервер слушает loopback. Проверяются Host, источник запроса и CSRF для изменяющих действий.
- Пароль мастера и шифрование базы включаются пользователем. Без заданного пароля локальные данные не становятся зашифрованными автоматически.
- Полный доступ администратора нужен отдельным диагностическим и ремонтным операциям. Сам статус Free не выдаёт права ОС.
- ИИ на собственном ключе обращается к выбранному провайдеру. Свободный текст может содержать персональные данные: не передавайте их провайдеру без подходящего основания и согласованных условий. Предпросмотр и подтверждение действий ИИ остаются обязательными.
- Подписанный пакет обновления подтверждает происхождение файлов. Полные исходники и сборка позволяют проверить код; подпись не заменяет проверки его поведения.
- На чужом компьютере защищённость локального сервера ограничена защищённостью самой ОС. Не используйте пароль и резервный код на заведомо скомпрометированной системе.

Каталоги клиентов, личные настройки и ключи не включаются в публикации и архивы обновления. Сборщик публичного комплекта принимает только явный перечень файлов. Сборка pull request не получает ключ подписи автора.
