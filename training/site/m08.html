Командная строка для ПК-мастера

📥 Версия для печати (.docx)

Шестой учебник курса. Командная строка — это главный профессиональный инструмент мастера. Половина диагностики делается не кликами в Параметрах Windows, а одной командой в окне командной строки за 2 секунды.

Учебник разделён на 6 частей:
1. CMD vs PowerShell — что чем отличается, когда что брать
2. Базовая навигация — папки, файлы, что куда положить
3. Диагностика системы — sfc, DISM, chkdsk, bootrec
4. Сеть — ipconfig, ping, tracert, netsh
5. Процессы и службы — tasklist, taskkill, sc, реестр
6. Готовые .bat-скрипты — что положить на флешку мастера

Часть 1. CMD vs PowerShell

В Windows есть две разные командные оболочки. Понимать разницу — важно.

Параметр CMD (cmd.exe) PowerShell (powershell.exe)
Кто старше С Windows NT, 1993 г. — старый С Windows 7, 2009 г. — современный
Синтаксис Простые команды (dir, ping, del) Команды вида Verb-Noun (Get-Process, Stop-Service)
Универсальность Только Windows, прост Windows + Mac + Linux (PowerShell Core 7+)
Удобство для админа Слабее Сильнее (объекты, конвейер, .NET)
Совместимость с .bat Полная Большинство работает через cmd /c
Цвет в логах Чёрно-белый Цветной (можно настроить)

Правило:
- CMD — для простых одноразовых команд, для совместимости со старыми скриптами, для .bat-файлов
- PowerShell — для всего серьёзного: диагностика SMART, журналы Windows, работа с реестром, циклы и условия

В большинстве случаев мастеру достаточно CMD. PowerShell нужен когда задача сложная.

Как запустить

CMD:
- Win+R → cmd → Enter (обычные права)
- Кнопка Пуск → набрать cmd → правой кнопкой «Запуск от имени администратора»
- Win+X → «Терминал» (Windows 11) → стрелка вниз → «Командная строка»

PowerShell:
- Win+R → powershell → Enter
- Win+X → «Терминал» (Windows 11) — открывается PowerShell по умолчанию
- Современный «Windows Terminal» из Microsoft Store — лучший вариант, поддерживает вкладки

От администратора — для большинства мастерских команд обязательно. Без админ-прав sfc, DISM, chkdsk, bootrec, netsh не работают.

Часть 2. Базовая навигация

2.1. Где я нахожусь

cd                     CMD: показать текущую папку
pwd                    PowerShell: то же самое (или cd без аргументов)

При запуске CMD/PowerShell вы обычно находитесь в C:\Users\<имя>\ — это «домашняя папка» пользователя.

2.2. Переход в папку

cd C:\Windows\System32          перейти в System32
cd ..                            на уровень выше
cd \                             в корень текущего диска
cd ~                             домой (только PowerShell)
D:                               сменить диск (CMD)
Set-Location D:\                 PowerShell-эквивалент

Подсказка: в Проводнике откройте папку → в адресной строке наберите cmd или powershell → Enter. Оболочка откроется уже в этой папке.

2.3. Что в папке

dir                  CMD: список файлов
dir /a               + скрытые файлы
dir /s               рекурсивно (включая подпапки)
dir *.txt            только .txt файлы
dir | more           постранично (если много)

ls                   PowerShell: то же что dir
Get-ChildItem        полное имя того же командлета
ls -Force            + скрытые
ls -Recurse          рекурсивно

2.4. Создание / удаление / переименование

mkdir test           создать папку test
md test              то же сокращение (CMD)
New-Item -ItemType Directory test    PowerShell

rmdir test           удалить ПУСТУЮ папку
rd /s /q test        удалить с содержимым (рекурсивно, без подтверждения)
Remove-Item -Recurse -Force test     PowerShell-эквивалент

del file.txt         удалить файл
Remove-Item file.txt PowerShell

ren old.txt new.txt  переименовать файл
Rename-Item old.txt new.txt

2.5. Копирование и перемещение

copy a.txt b.txt              скопировать
xcopy a.txt b.txt             более мощная версия
xcopy src dst /E /I /Y        копировать папку рекурсивно, без подтверждения

robocopy src dst /E /MIR      зеркальное копирование (продвинутый xcopy)
robocopy src dst /MT:8        в 8 потоков (быстрее)

move a.txt c:\arc\            переместить
Move-Item a.txt c:\arc\       PowerShell

Robocopy — главный инструмент бэкапа на Windows. Параметры:
- /E — копировать все подпапки (вкл. пустые)
- /MIR — зеркало (удалит в назначении то чего нет в источнике — осторожно!)
- /Z — продолжать при обрыве
- /R:1 — 1 повторная попытка при ошибке (вместо 1 миллиона по умолчанию)
- /W:1 — пауза 1 секунда между попытками
- /XJ — игнорировать junction-точки (защита от циклов)
- /NFL /NDL /NJH /NJS — сокращённый лог (без списка файлов и заголовков)

Пример полноценного бэкапа:

robocopy "C:\Users\Иван\Documents" "D:\Backup\Documents" /E /Z /R:1 /W:1 /XJ

2.6. Просмотр содержимого файла

type log.txt              CMD: показать содержимое
type log.txt | more       постранично

Get-Content log.txt       PowerShell
cat log.txt               сокращение (алиас)
Get-Content log.txt -Tail 20    последние 20 строк (как tail)

2.7. Поиск в файле и по файлам

findstr "error" log.txt           CMD: найти слово в файле
findstr /i "error" log.txt        регистронезависимо
findstr /s "TODO" *.cs            рекурсивно по всем .cs

Select-String "error" log.txt     PowerShell
Get-ChildItem -Recurse *.txt | Select-String "TODO"     поиск по всем .txt в подпапках

Часть 3. Диагностика системы

Это главная часть для ПК-мастера. Эти команды на каждом ремонте.

3.1. SFC — проверка системных файлов

sfc /scannow            проверка и автопочинка
sfc /verifyonly         только проверка, без починки

Что делает: сканирует все системные файлы Windows, сравнивает с эталонными в C:\Windows\WinSxS, повреждённые заменяет.

Время: 5-15 минут на SSD, 15-45 на HDD. Безопасно для данных пользователя — их не трогает.

Лог результатов: C:\Windows\Logs\CBS\CBS.log — там детально что нашёл.

Если sfc показал «Защита ресурсов Windows нашла повреждённые файлы, но не смогла исправить» — нужен DISM сначала.

3.2. DISM — починка хранилища компонентов

DISM /Online /Cleanup-Image /CheckHealth         быстрая проверка (минута)
DISM /Online /Cleanup-Image /ScanHealth          детальная проверка (~5 минут)
DISM /Online /Cleanup-Image /RestoreHealth       автовосстановление из Windows Update

Что делает: чинит хранилище компонентов Windows (C:\Windows\WinSxS), откуда sfc берёт эталонные файлы. Если хранилище битое — sfc не сможет починить файлы.

Правильный порядок при проблемах с системными файлами:
1. DISM /Online /Cleanup-Image /RestoreHealth (10-30 минут)
2. sfc /scannow (5-15 минут)
3. Перезагрузка

Если интернета нет — DISM не работает. Нужен ISO Windows такой же версии в D:\Win11ISO\:

DISM /Online /Cleanup-Image /RestoreHealth /Source:WIM:D:\Win11ISO\sources\install.wim:1 /LimitAccess

3.3. CHKDSK — проверка диска

chkdsk C:                       только чтение, без правок
chkdsk C: /f                    + автопочинка ошибок NTFS
chkdsk C: /f /r                 + проверка bad-секторов (ОЧЕНЬ долго)
chkdsk C: /f /r /x              + размонтировать диск принудительно

Что делает: проверяет файловую систему NTFS. /r дополнительно сканирует физические сектора диска и помечает битые.

Время: /f — 5-30 минут. /r на терабайтном диске — 6-12 часов. Запускать только когда есть время.

Для системного диска: chkdsk C: /f /r попросит перезагрузку — проверка пройдёт до загрузки Windows.

Когда запускать chkdsk:
- Симптомы: тормоза, зависания при работе с файлами, ошибки чтения/записи
- SMART показывает Reallocated Sector Count > 0 (битые сектора)
- Внезапные перезагрузки во время копирования файлов

Не лечит:
- Логические повреждения файлов (это sfc)
- Виды нарушения NTFS — иногда тоже не справляется, нужны Recuva/TestDisk

3.4. BOOTREC — восстановление загрузчика

Запускается из среды восстановления WinRE (выруби ПК 3 раза подряд при загрузке).

bootrec /fixmbr                 восстановить главную загрузочную запись (MBR)
bootrec /fixboot                восстановить сектор загрузки активного раздела
bootrec /scanos                 поиск установленных Windows
bootrec /rebuildbcd             пересоздать BCD (Boot Configuration Data)

Когда: «No bootable device», «Operating system not found», «BOOTMGR is missing», после неудачного клонирования диска.

Полный сценарий восстановления загрузки:

bootrec /fixmbr
bootrec /fixboot
bootrec /scanos
bootrec /rebuildbcd

Если /fixboot выдаёт «Access denied» — это UEFI-система. Тогда:

bcdboot C:\Windows /s C: /f UEFI

(C: — буква раздела Windows, может быть другой в WinRE).

3.5. POWERCFG — диагностика батареи и питания

powercfg /batteryreport         отчёт по аккумулятору ноута (HTML)
powercfg /energy                диагностика энергопотребления (час работы → отчёт)
powercfg /requests              что мешает уходу в сон (играющая программа, например)
powercfg /lastwake              что разбудило ПК последний раз
powercfg /sleepstudy            детальная история сна и пробуждений

powercfg /batteryreport — главный инструмент при покупке б/у ноута. Покажет:
- Дизайн-ёмкость (как было новым)
- Полная зарядка сейчас (как износилось)
- Износ в процентах
- История циклов

При покупке б/у ноута — попроси клиента запустить эту команду перед сделкой.

3.6. WINSAT — оценка производительности

winsat formal                   полный тест производительности (5-10 минут)
winsat disk                     только тест диска

Результат в C:\Windows\Performance\WinSAT\DataStore\*.xml. В Windows 11 этого «индекса производительности» больше нет в Параметрах, но команда работает.

Полезно: «до» и «после» апгрейда (SSD/RAM) — показать клиенту разницу.

Часть 4. Сеть

4.1. IPCONFIG — что у меня с сетью

ipconfig                всё кратко
ipconfig /all           подробно: MAC-адреса, DHCP, DNS-серверы
ipconfig /release       освободить IP-адрес
ipconfig /renew         запросить новый IP
ipconfig /flushdns      очистить кэш DNS (если сайты вдруг не открываются)
ipconfig /displaydns    показать текущий кэш DNS

Главное в /all:
- IPv4-адрес — твой IP в локальной сети (обычно 192.168.0.x или 192.168.1.x)
- Маска подсети — обычно 255.255.255.0
- Основной шлюз — IP роутера (обычно 192.168.0.1 или 192.168.1.1)
- DNS-серверы — кто переводит имена в IP (обычно 192.168.x.1 = роутер, либо провайдерский, либо 1.1.1.1/8.8.8.8 если клиент настроил)
- MAC-адрес — физический адрес сетевой карты (нужен для привязки в роутере)

Подозрительные IP:
- 169.254.x.x — APIPA, DHCP не сработал. Сетевая карта сама себе придумала адрес. Лечится: ipconfig /release + /renew, либо netsh winsock reset
- DNS из «странных» провайдеров типа 185.x.x.x без явного выбора клиента — подменён вирусом, проверь

4.2. PING — есть ли связь

ping 8.8.8.8                     проверить связь с Google DNS
ping -t 8.8.8.8                  бесконечный пинг (Ctrl+C для остановки)
ping -n 100 8.8.8.8              100 пакетов
ping -l 1500 8.8.8.8             пакет 1500 байт (тест MTU)
ping ya.ru                       по имени (проверяет DNS тоже)

Что говорят результаты:
- <5 мс — отлично, локальная сеть
- 5-50 мс — норма для близких серверов в России
- 50-150 мс — норма для зарубежных
- >300 мс — далеко или плохая линия
- Превышен интервал ожидания (timeout) — сервер не отвечает или маршрут не работает
- Не удалось обнаружить узел — DNS не работает или имени нет

4.3. TRACERT — путь до сервера

tracert 8.8.8.8                  через какие узлы идёт трафик
tracert -d ya.ru                 без обратного DNS (быстрее)

Показывает каждый «прыжок» (hop) до целевого сервера. Полезно для диагностики «где именно тормозит» — иногда видно что у клиента ОК, у провайдера ОК, а у дальнего узла торможение.

4.4. NSLOOKUP — DNS-запрос

nslookup ya.ru                       стандартный DNS клиента
nslookup ya.ru 1.1.1.1               через Cloudflare DNS
nslookup ya.ru 8.8.8.8               через Google DNS

Полезно когда клиент жалуется «сайт не открывается, а у меня открывается». Может оказаться что у клиента DNS-сервер тормозит или возвращает фейковый IP.

4.5. NETSTAT — что слушает сеть на ПК

netstat -an                          все соединения и порты
netstat -ano                         + PID процесса
netstat -ano | findstr :80           кто слушает порт 80
netstat -ano | findstr LISTENING     только серверные порты

Полезно при подозрении на вирус — увидеть «странное» исходящее соединение или непонятный открытый порт.

4.6. NETSH — сетевая магия

netsh winsock reset                  сброс Winsock (после вирусов часто помогает)
netsh int ip reset                   сброс TCP/IP стека
netsh int ip reset reset.log         с логом куда писать
netsh interface show interface       список сетевых интерфейсов
netsh wlan show profiles             список сохранённых Wi-Fi
netsh wlan show profile name="X" key=clear    показать пароль Wi-Fi (с правами админа)

netsh winsock reset + netsh int ip reset + перезагрузка — стандартный приём при «вирус что-то сломал в сети, теперь интернет не работает».

netsh wlan show profile name="X" key=clear — спасает когда клиент: «забыл пароль от своего Wi-Fi, как узнать?». Если он сохранён на ПК — посмотришь в открытом виде.

Часть 5. Процессы, службы, реестр

5.1. TASKLIST / TASKKILL — управление процессами

tasklist                                 все процессы
tasklist /v                              + название окна
tasklist | findstr chrome                все chrome.exe
tasklist /fi "MEMUSAGE gt 500000"        процессы > 500 МБ памяти

taskkill /im notepad.exe                 убить все блокноты
taskkill /pid 1234                       убить процесс с PID 1234
taskkill /f /im notepad.exe              принудительно (как Конец задачи в Диспетчере)

Альтернатива в PowerShell:

Get-Process | Sort-Object WS -Descending | Select-Object -First 10  топ-10 по памяти
Stop-Process -Name notepad -Force

5.2. SC — управление службами Windows

sc query                                 все службы
sc query state= all                      включая остановленные
sc query "Print Spooler"                 одна служба

sc start "Print Spooler"                 запустить
sc stop "Print Spooler"                  остановить

sc config "Print Spooler" start= auto    автозапуск
sc config "Print Spooler" start= disabled    отключить (Win7+)

sc delete "BadService"                   удалить службу (вирусы часто оставляют)

Внимание к пробелам: в start= auto обязательно пробел после знака =, без пробела перед. CMD так требует.

5.3. NET — устаревшие, но рабочие команды

net user                          список пользователей
net user Иван                     инфо по пользователю
net user Иван NewPass             сменить пароль (с админ-правами)
net user Иван /add                создать пользователя
net localgroup Администраторы Иван /add    добавить в группу

net start                         запущенные службы
net stop "Имя"                    остановить

net share                         расшаренные папки
net use                           подключенные сетевые диски
net use Z: \\server\share         подключить
net use Z: /delete                отключить

5.4. REG — работа с реестром

reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion" /v ProductName
reg add "HKCU\Software\Test" /v MyKey /t REG_SZ /d "Hello" /f
reg delete "HKCU\Software\Test" /f
reg export "HKCU\Software" backup.reg            бэкап ветки в файл
reg import backup.reg                            восстановить

Топовые места в реестре где часто живут вирусы (проверить руками):

HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Browser Helper Objects

Это автозагрузка и расширения IE/Edge. После очистки от рекламы — проверь что там не остался мусор.

5.5. WMIC — устарел, но иногда нужен

wmic cpu get name                       название процессора
wmic memorychip get capacity,speed      ОЗУ — ёмкость и частота каждой плашки
wmic diskdrive get model,size           диски — модель и объём
wmic baseboard get product,manufacturer  материнка
wmic os get caption,version             версия Windows

В новых Windows 11 WMIC объявлен устаревшим — заменяется на PowerShell Get-CimInstance. Пример:

Get-CimInstance Win32_Processor | Select-Object Name
Get-CimInstance Win32_PhysicalMemory | Select-Object Capacity, Speed

5.6. SYSTEMINFO — общая инфа о ПК

systeminfo                              всё про ПК
systeminfo | findstr "Память"            только про память

Быстрый снимок ПК для отчёта: модель ПК, версия Windows, дата установки, всё ОЗУ и сколько свободно, домен/рабочая группа, аптайм.

Часть 6. Готовые .bat-скрипты для флешки мастера

Это типовые скрипты которые стоит положить на флешку и запускать в один клик. Все они есть в /скрипты/ дашборда Verus.

6.1. Чистка временных файлов

cleanup-temp.bat — освобождает 1-5 ГБ за минуту:

@echo off
chcp 65001 >nul
echo === Чистка временных файлов ===
echo.

echo Чищу %TEMP%...
del /q /f /s "%TEMP%\*.*" 2>nul
for /d %%i in ("%TEMP%\*") do rd /s /q "%%i" 2>nul

echo Чищу системный TEMP...
del /q /f /s "C:\Windows\Temp\*.*" 2>nul
for /d %%i in ("C:\Windows\Temp\*") do rd /s /q "%%i" 2>nul

echo Чищу Prefetch...
del /q /f "C:\Windows\Prefetch\*.*" 2>nul

echo Чищу кэш загрузок Windows Update (если не идут обновления!)
net stop wuauserv 2>nul
del /q /f /s "C:\Windows\SoftwareDistribution\Download\*.*" 2>nul
net start wuauserv 2>nul

echo.
echo === Готово ===
pause

Запуск: правой кнопкой → «Запуск от имени администратора». Без админа эти папки не почистятся.

6.2. Сводный отчёт о ПК

pc-report.bat — генерирует отчёт в report.txt:

@echo off
chcp 65001 >nul
set REPORT=%~dp0report_%COMPUTERNAME%_%DATE:/=-%.txt
echo === Отчёт о ПК === > "%REPORT%"
echo Дата: %DATE% %TIME% >> "%REPORT%"
echo Имя ПК: %COMPUTERNAME% >> "%REPORT%"
echo Пользователь: %USERNAME% >> "%REPORT%"
echo. >> "%REPORT%"

echo === Система === >> "%REPORT%"
systeminfo | findstr /R /C:"Имя ОС" /C:"Версия ОС" /C:"Дата установки" /C:"Полная физическая память" /C:"Доступная физическая память" >> "%REPORT%"
echo. >> "%REPORT%"

echo === Процессор === >> "%REPORT%"
wmic cpu get Name,NumberOfCores,NumberOfLogicalProcessors /value 2>nul | findstr "=" >> "%REPORT%"
echo. >> "%REPORT%"

echo === Память === >> "%REPORT%"
wmic memorychip get Capacity,Speed,Manufacturer /value 2>nul | findstr "=" >> "%REPORT%"
echo. >> "%REPORT%"

echo === Диски === >> "%REPORT%"
wmic diskdrive get Model,Size,InterfaceType /value 2>nul | findstr "=" >> "%REPORT%"
echo. >> "%REPORT%"

echo === Сеть === >> "%REPORT%"
ipconfig /all | findstr /C:"IPv4" /C:"MAC" /C:"Шлюз" /C:"DNS" >> "%REPORT%"
echo. >> "%REPORT%"

echo Отчёт сохранён в: %REPORT%
notepad "%REPORT%"

Показать клиенту что у него за железо и какая версия Windows — за 10 секунд.

6.3. Сброс сети после вирусов

net-reset.bat:

@echo off
chcp 65001 >nul
echo === Сброс сети ===
echo.
echo Винсок:
netsh winsock reset
echo.
echo TCP/IP стек:
netsh int ip reset
echo.
echo Прокси:
netsh winhttp reset proxy
echo.
echo Кэш DNS:
ipconfig /flushdns
echo.
echo === Готово. Перезагружай ПК! ===
pause

После запуска обязательно перезагрузка — иначе сброс не применится.

6.4. SFC + DISM — лечение системных файлов

sfc-dism.bat:

@echo off

echo Внимание: займёт 15-45 минут!

6.6. Список автозагрузки

autorun-list.bat:

@echo off
chcp 65001 >nul
echo === Автозагрузка пользователя ===
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" 2>nul
echo.
echo === Автозагрузка системы ===
reg query "HKLM\Software\Microsoft\Windows\CurrentVersion\Run" 2>nul
echo.
echo Для удаления — Autoruns.exe (на флешке).
pause

Кодировка вывода — частая проблема

В .bat-скриптах с русским текстом нужно указать кодировку, иначе будут «крякозябры».

В начало .bat добавь:

chcp 65001 >nul

65001 — UTF-8. Файл .bat должен быть сохранён в UTF-8 с BOM или в CP866 (старая кодировка CMD).

PowerShell-скрипты (.ps1) — UTF-8 с BOM обязательно для PowerShell 5.1 (стандарт Windows 10/11). Без BOM кириллица читается как cp866 и парсер ломается.

Главные правила работы в командной строке

  1. От администратора — для всех системных команд (sfc, DISM, chkdsk, bootrec, net, sc, reg HKLM, netsh). Без прав — «Access denied»
  2. Tab-завершение — начни писать имя → Tab → автодополнит
  3. Стрелки вверх/вниз — история введённых команд
  4. F7 — окно истории команд в текущем сеансе CMD
  5. Ctrl+C — прервать команду (не «копировать»! Для копирования — выделить мышью + Enter)
  6. > файл.txt — записать вывод в файл (затирает существующий)
  7. >> файл.txt — дописать в конец
  8. команда1 | команда2 — выход первой подаётся на вход второй
  9. команда | findstr "X" — фильтр по тексту
  10. команда | more — постранично

Что положить на флешку мастера

В /скрипты/ дашборда Verus уже есть:
- cleanup-temp.bat — чистка
- pc-report.bat — отчёт
- net-reset.bat — сброс сети
- sfc-dism.bat — лечение файлов

Дополнительно можешь добавить свои под типовые задачи. Хороший мастер за полгода накапливает 20-30 готовых скриптов под все ситуации.

Стандартное правило: перед запуском на чужом ПК — прочитай скрипт глазами. Не запускай чужие .bat «вслепую», особенно из интернета.

Главное

Командная строка — это в 5-10 раз быстрее чем клики в Параметрах Windows. Освой 30-40 базовых команд из этой главы — этого хватит на 90% мастерских задач.

sfc /scannow, DISM /Online /Cleanup-Image /RestoreHealth, chkdsk C: /f, ipconfig /all, ping ya.ru, netsh winsock reset, tasklist, taskkill /f /im X.exe — это обязательный минимум который должен сидеть в пальцах.

Остальное — справочник, к которому возвращаешься по необходимости.
