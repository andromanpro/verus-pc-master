# Участие в разработке

Принимаются исправления ошибок, улучшения доступности и воспроизводимые сценарии работы ПК-мастера. Перед большой доработкой опишите задачу в issue.

1. Воспроизведите проблему на вымышленных данных или тестовом компьютере.
2. Меняйте только необходимые файлы. Добавьте проверку поведения, если исправление затрагивает данные, безопасность или сложную логику.
3. Выполните проверки из README. Для действий над Windows используйте отдельную тестовую систему.
4. В pull request опишите проблему, результат и реально выполненные проверки.

Не прикладывайте данные клиентов, ключи API, токены, пароли, реальные отчёты о компьютерах, личные пути и адреса. Уязвимости сообщайте по SECURITY.md.

Оригинальные вклады принимаются под MPL-2.0. Отправляя вклад, вы подтверждаете право предоставить его под этой лицензией. Это не передача исключительных прав и не отдельное разрешение закрыть чужой вклад. Для стороннего кода обязательны происхождение и уведомления.

PowerShell должен работать в Windows PowerShell 5.1. Файлы `.ps1` с русскими строками сохраняйте в UTF-8 с BOM. Сервер запускается локально; не расширяйте сетевую доступность без отдельного обсуждения. Опасные действия сохраняют предварительный просмотр, явное подтверждение и проверку параметров.
