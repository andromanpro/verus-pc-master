# VERUS Free и планы Pro

## Что доступно сейчас

VERUS Free — бесплатный открытый инструмент для одного ПК-мастера. Его можно использовать в оплачиваемой работе. Активация флешки, аккаунт и подписка для локального ядра не нужны.

| Возможность | Free 0.7 |
|---|---|
| Диагностика компьютера, сеть, периферия | Да; наличие показаний зависит от датчиков, прав ОС и установленных утилит |
| Ручное обслуживание Windows | Да, с проверкой параметров и подтверждениями |
| Клиенты, история, сметы, приёмка и передача | Локально, без искусственного лимита записей |
| Шифрование базы, экспорт и резервные копии | Да; пароль задаётся пользователем |
| Резервирование на собственный Яндекс.Диск | Да, после настройки пользователем |
| ИИ | Собственный ключ провайдера, отдельная оплата запросов провайдеру |
| Обучение, справочник и свой набор программ | Да |
| Исправления ошибок и безопасности | Бесплатно |

## Что планируется для Pro

Управляемый ИИ с включённым бюджетом, синхронизация устройств, совместная работа и приоритетная помощь. Эти сервисы ещё не продаются, цена и сроки не объявлены. Наличие экспериментального кода интеграций в исходниках не означает готовности сервиса.

Free остаётся самостоятельной программой. В будущем завершение подписки не должно блокировать локальную базу, чтение истории или экспорт. Исправления безопасности не станут платной функцией.

## Переход со старой версии

Обновление сохраняет данные и индивидуальные настройки. Файл старой лицензии можно оставить: он больше не ограничивает локальные возможности. Free не требует перевыпуска токена после замены флешки.

Код лицензируется по MPL-2.0, сторонние компоненты — по своим условиям. Будущие услуги Pro будут иметь отдельные условия. Публичный код не является обещанием доступности платной инфраструктуры.
